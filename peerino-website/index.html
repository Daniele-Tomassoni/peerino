Peerino

P2P file sharing without cloud, without accounts, without intermediaries.

🔗 Share via link

Generate a link, send it anywhere. Recipients download from their browser, no app required.

📥 Receive files

Create an inbox link and let anyone send you files. No account, no app.

🔒 End-to-end encrypted

WebRTC with DTLS. Files never touch a cloud server.

🏠 LAN fallback

On the same network, transfers stay local. No internet, no relay, maximum speed.

How it works

Two simple flows: send a file to anyone, or receive files from anyone.

📤 Send a file

  1. Select the file in the Shared Files window
  2. Click Generate Link
  3. Copy the link and send it to anyone

📥 Receive a file

  1. Click Create Inbox
  2. Copy the generated link and send it to anyone
  3. They upload files from their browser, no app required
