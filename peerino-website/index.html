Peerino

P2P file sharing without cloud, without accounts, without intermediaries.

🔗 Share via link Generate a link, send it to anyone. They download from their browser.
📥 Receive via link Create an inbox link and receive files from anyone, no app required.
🔒 Private End-to-end encrypted WebRTC. Files never touch a cloud server.
🏠 LAN fallback Direct transfer on the same network, without going through the internet.
